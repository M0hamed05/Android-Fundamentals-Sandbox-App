
# An android application built to practice the **Jetpack Compose** Fundamentals.


## 🛠 Tech Stack
*   **UI Framework:** Jetpack Compose (Declarative UI)
*   **Local Database:** Room (for Notes & To-Do persistence)
*   **Networking:** Retrofit / API integration (Shop data)
*   **Navigation:** Navigation Compose with Bottom Bar
*   **Concurrency:** Kotlin Coroutines

## ✨ Key Features
*   **Productivity Suite:** 
    *   **Notes & Todo:** Full CRUD operations using Room database.
    *   **Stopwatch:** Real-time state management in Compose.
*   **API Integration:** A dynamic Shop screen fetching item names via remote API.
*   **Central Hub:** Seamless navigation between modules via a persistent Bottom Navigation Bar.

## Not covered yet
*  **SharedPrefs**
*  **dependency injection**
